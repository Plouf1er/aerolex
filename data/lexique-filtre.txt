# LEXIQUE AERO — candidats juges (Aero Coach, 37 seances)
# Format bloc CORPUS : terme <TAB> occurrences <TAB> nb_seances
#   (nb_seances = 0 quand le terme vient d'une passe sans comptage par seance)
# Format bloc METIER : terme (une par ligne)
#
# ORIGINE DES TERMES — deux blocs, deux statuts
#   corpus  = le terme APPARAIT reellement dans les seances. Presence
#             verifiee PAR PROGRAMME contre un index construit sur les
#             158 fichiers du corpus (sessions/*.html + data_*.py +
#             meteo_utils / glos_utils / plan_seances / docs md).
#             -> lien actif sur les pages de seance.
#   metier  = vocabulaire aero francais standard, reellement employe en
#             aeronautique, mais ABSENT du corpus. Fiche a creer,
#             PAS de lien actif tant que le mot n'apparait nulle part.
#
# Le classement corpus/metier est MECANIQUE : il decoule uniquement du
# test de presence, jamais d'un jugement. Un terme juge pertinent mais
# introuvable dans le corpus va en METIER, il n'est jamais promu corpus.
#
# REGLE D'AFFICHAGE — LONGEST MATCH WINS
#   A l'affichage sur les pages de seance, une expression de plusieurs
#   mots est PRIORITAIRE sur une expression plus courte : on trie les
#   termes par nombre de mots puis par longueur de chaine decroissante,
#   le premier qui matche gagne, et une portion de texte deja consommee
#   par un lien n'est plus candidate pour un terme plus court.
#   Ex. `ft/min` l'emporte sur `ft` ; `vent arriere` sur `vent` ;
#       `point de rosee` sur `point`.
#
# NOTE — atomes polysemiques
#   Quelques atomes retenus sont aussi des mots courants du francais
#   (`va`, `moment`, `point`, `plan`, `air`). Ils sont conserves car ils
#   portent un sens aero reel dans le corpus (Va = vitesse de manoeuvre,
#   moment = masse et centrage). La regle longest-match les protege :
#   `vitesse de manoeuvre` et `moment de tangage` gagnent avant eux.
#
# EXCLUSIONS — villes, lieux, immatriculations (decision Louis 02/08/2026)
#   Un nom de ville / de region / de pays n'est PAS un terme aero : on ne
#   definit pas de villes dans un glossaire de vol. 34 entrees retirees
#   (paris, orly, montpellier, bordeaux, bale, clermont, toussus,
#   toussus-le-noble, beauvais, brest, chartres, etampes, meaux,
#   mulhouse, nice, pontoise, roissy, toulouse, villacoublay, france,
#   ile-de-france, idf, chavenay, coulommiers, enghien, lognes, lyon,
#   marseille, moisselles, nantes, persan, rennes, saint-cyr,
#   strasbourg). Idem pour les immatriculations d'aeronefs : 2 entrees
#   retirees (f-haat, fm-at) — une immat identifie une machine, pas un
#   concept.
#
#   CONSERVES malgre l'apparence geographique :
#     - les 50 codes OACI (lfpn, lfpo, lfsb, lfmt, lfbd, lflc, ...) :
#       un code OACI designe un TERRAIN, avec sa carte VAC, ses pistes,
#       ses procedures, son tour de piste -> il merite sa fiche.
#     - `tma paris` : designation d'espace aerien, pas une ville.
#     - `mer`, `terre`, `nord`, `sud`, `ouest` : atomes aero reels
#       (brise de mer, brise de terre, nord magnetique, nord vrai,
#       secteurs cardinaux de navigation). Proteges par longest-match.
#     - `hippodrome` : forme du circuit d'attente, pas un lieu.
